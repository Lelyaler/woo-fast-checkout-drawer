# WooCommerce Fast Checkout & Slide Cart Drawer

Коммерческий модуль для интернет-магазинов на WooCommerce, объединяющий выезжающую корзину (Slide Cart Drawer) с живым пересчетом количества товаров и быстрое оформление заказа в 1 клик (1-Click Express Checkout) без прохождения стандартного многошагового чекаута.

Полностью совместим с WooCommerce High-Performance Order Storage (HPOS) и архитектурой нативных хуков ядра WooCommerce.

---

## Возможности

1. **Снижение брошенных корзин (Cart Abandonment)**: Стандартный чекаут WooCommerce требует перехода по цепочке `Страница товара` → `Корзина` → `Чекаут (12+ полей)` → `Страница оплаты`. Плагин сокращает путь до одного клика прямо со страницы товара или из выезжающего дровера.
2. **Бесшовный UX (Zero Page Reloads)**: Добавление товара, удаление и изменение количества (+ / -) происходят мгновенно через AJAX без перезагрузки страницы благодаря интеграции с `woocommerce_add_to_cart_fragments`.
3. **Геймификация среднего чека (AOV Boost)**: Встроенный динамический прогресс-бар бесплатной доставки в реальном времени мотивирует покупателя добрать товаров до нужной суммы.
4. **Совместимость с современным стеком**: Нативная поддержка HPOS (`custom_order_tables`), что предотвращает падение производительности на базах с десятками тысяч заказов.

---

## Архитектура и ключевые модули

Плагин написан по принципам ООП (PHP 7.4 - 8.3+) с четким разделением обязанностей:

- **`WooFastCheckout\Plugin`** — центральный контроллер-синглтон, инициализация хуков, загрузка зависимостей и локализация.
- **`WooFastCheckout\Cart_Drawer`** — рендеринг выезжающего дровера, плавающей кнопки корзины, динамический расчет прогресса бесплатной доставки и интеграция с фрагментами WooCommerce (`woocommerce_add_to_cart_fragments`).
- **`WooFastCheckout\Quick_Buy`** — внедрение кнопки «Купить в 1 клик» в карточки простых и вариативных товаров через хук `woocommerce_after_add_to_cart_button` и шорткод `[wfcd_quick_buy]`.
- **`WooFastCheckout\Order_Handler`** — серверная обработка быстрого заказа:
  - Валидация и санитария полей клиента;
  - Создание заказа через `wc_create_order()`;
  - Назначение товаров, адресов и способов оплаты;
  - Вызов стандартных событий `woocommerce_checkout_order_processed` и триггера отправки email-уведомлений покупателю и администратору (`WC_Email_New_Order`);
  - Демонстрация хука пересчета корзины `woocommerce_before_calculate_totals`.
- **`WooFastCheckout\Rest_Api`** — регистрация публичных эндпоинтов `/wp-json/wfcd/v1/cart-state` и `/wp-json/wfcd/v1/quick-order` для Headless E-commerce или интеграции с внешними приложениями.
- **`WooFastCheckout\Admin_Settings`** — панель настроек в меню **WooCommerce → Express Checkout** с управлением положением дровера, тумблерами функций, выбором способа оплаты по умолчанию и колорпикером кнопок (`wp-color-picker`).

## Используемые хуки ядра WooCommerce

| Хук | Тип | Назначение в плагине |
| --- | --- | --- |
| `before_woocommerce_init` | Action | Декларация поддержки High-Performance Order Storage (`custom_order_tables`) |
| `woocommerce_add_to_cart_fragments` | Filter | Синхронизация содержимого дровера и счетчиков без перезагрузки страницы |
| `woocommerce_after_add_to_cart_button` | Action | Автоматический вывод кнопки быстрого заказа рядом с кнопкой добавления в корзину |
| `woocommerce_before_calculate_totals` | Action | Перехват и валидация расчета итоговых сумм перед калькуляцией скидок |
| `woocommerce_checkout_order_processed` | Action | Совместимость с системами аналитики (GA4, Facebook Pixel) и CRM-плагинами |
| `woocommerce_new_order` | Action | Уведомление сторонних обработчиков об успешном создании нового заказа |

---

## Установка

1. Скопируйте папку `woo-fast-checkout-drawer` в директорию `/wp-content/plugins/`.
2. Активируйте плагин в консоли WordPress: **Плагины → Установленные**.
3. Перейдите в раздел **WooCommerce → Express Checkout** для настройки цветов, порога бесплатной доставки и поведения дровера.
